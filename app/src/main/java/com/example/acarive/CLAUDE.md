## 현대자동차 차량용 APP 개발 공모전 기획

**혼자만의 드라이브를 즐기는 2030을 위한 시청각적 즐거움 제공**

### 기능
(1) 상황, 시간에 맞는 플레이리스트

날씨, 현재 주행 중인 환경, 속도, 현재 주행 중인 드라이브 코스, 계절, 급격한 변화 감지 등 고려
-> 스포티파이 연동

(2) 좋은 풍경이 있는 코스 추천
풍경 데이터: 공공기관, 외부 API를 이용한 풍경 데이터 추가

추천 알고리즘: 현재 위치에서 왕복 2-3시간 인 것. 을 아래 기준에 맞추어 추천
명시적 프로필의 취항태그(선호하는 드라이브 코스를 몇 가지 테마로 나누어 응답받기)
타 사용자의 드라이브 기록을 바탕으로 사람들이 자주 이용하는 경로 추천

-> 추천 완료되면 send to car 해서 차량 네비게이션으로 이동 후 차량 간접조명이나 분위기를 코스 분위기와 맞추기


추천 시점:
1) 찍고 출발(기본 왕복 시간 2~3시간인 코스 5개 메인화면에 추천)
2) 주행 중에 일정 시간 간격으로 하나씩 추천해서 Y/N 응답받기 - 알림 방식은 논의 필요

(3) 드라이브별 운전 경로를 기록 영상으로 쌓아주기 [레퍼런스: 2026년 나의 이동거리]

(4) 그 외 사항

어떻게 드라이브 목적 / 다른 목적 주행을 구분할까?: 슬라이드 버튼으로 직접 입력받기

즐겨찾기 기능: 실제로 가보지 않았지만 가보고 싶은 경로, 가봤더니 좋은 경로 등 저장하고 싶은 경로를 즐겨찾기할 수 있는 기능 제공
